# Photographic Assets & Credits (`docs/ASSETS_CREDITS.md`)

All sample photography bundled with the **NextStopTurkey — Anatolian Atlas** theme preview is stored locally under `web-next/public/demo/*.jpg`, indexed in a single TypeScript registry (`web-next/src/lib/data/demo-images.ts`), and served via Next.js `<Image>` (`next/image`) with automatic `AVIF` and `WebP` conversion.
